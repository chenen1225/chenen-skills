# 公众号文章撰写（gzh-write）

把"一个选题 / 大纲 / 素材"变成一篇符合陈恩公众号风格的文章 Markdown。本技能固化「恩嗲 8 条公众号写作规矩」，位于选题（gzh-topic）之后、配图 / 封面 / HTML / 推送之前。

## 触发场景

- 用户："写篇公众号文章""起草推文""按我的风格写""套写作规矩"
- 用户给选题、大纲、或口述素材，要落成公众号文
- 不触发：纯技术文档、非公众号长文

## 硬性写作规矩（8 条，逐条落实）

1. **导读先行**：标题下必须有一段 `导读：……`，一句话概括全文价值，让读者决定要不要读。
2. **文末金句必含**：结尾一句 *斜体升华*（招牌动作，如"工具只是拐杖，走路的人是你"）。
3. **第一人称 + 真实数据**：用"我"的真实故事，配具体数字（67 分 / 1020 万 token / 183 天……），不编。
4. **分章编号结构**：用 01/02 或 一/二/三 切大块，手机扫读友好。
5. **加粗抛结论**：每节末一句加粗"金句式"总结，快速抓重点。
6. **口语对话感**："说实话""不兜圈子"，像朋友聊天。
7. **先价值后带货**：工具自然植入，敢坦诚局限（"不能替代人"），不硬广。
8. **互动钩子（按文类区分，见下）**：每篇文末都要有，形式随文类变。

## 文章骨架（推荐）

```markdown
# 标题（口语、有数字或冲突感）

> 导读：……（一句话价值）

## 01 小标题
正文……（口语、第一人称、真实数据）
**本节金句（加粗结论）**

## 02 小标题
……

*文末金句（斜体升华）*

【互动钩子区，按文类选模板】
```

- 图注必须独立成段：`<p align="center">图N：……</p>`，不要只放 `![](...)` 的 alt（公众号不渲染 alt 为可见图注）。
- 图片路径统一 `imgs/<主题>/`。

## 互动钩子模板（按文类选）

| 文类 | 钩子形式 | 示例 |
|------|----------|------|
| 软件广告 / 带货文 | 具体提问 + 低门槛奖励 | "评论区留言，前 5 名送免费评测" |
| AI 知识专题 / 科创知识分享 | 知识向互动（抛议题 / 征集痛点 / 引导收藏转发 / "你最想搞懂哪块下期写"） | **不送实物奖励** |
| 高企知识（科技创新 / 研发管理） | 必挂「高企认定智能助手」蓝色硬广卡（品牌蓝 #1677FF，含产品截图 + 「阅读原文」蓝条） + 知识向互动钩子 | 硬广不能省 |
| 纯 AI 知识（非高企相关） | 仅知识向互动钩子 | **不挂硬广** |

> 硬规定（2026-08-03）：科创 / 研发管理类文章结尾必打「高企认定智能助手」广告，与知识向互动钩子并存。

## 高企知识类文末标准蓝卡（规范要点）

- 品牌蓝 `#1677FF` 背景卡
- 含产品截图 + 「阅读原文」蓝条按钮
- 文案引导体验「高企认定智能助手」
- 具体 HTML 模板随发布工作流（gzh-ops）落地，本技能只定规范

## 自测清单（交付前逐条勾）

- [ ] 有导读？有文末斜体金句？
- [ ] 用了"我"的真实故事 + 具体数字？
- [ ] 分章编号？每节有加粗结论？
- [ ] 口语感够吗？有"说实话"这类词？
- [ ] 价值在前、带货在后、不硬吹？
- [ ] 互动钩子按文类选对了吗？（高企类硬广不能漏）
