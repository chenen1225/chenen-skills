# HUM-Socratic v2.0 技能发布说明

## 简介

HUM-Socratic 是一个融合人本主义心理学与苏格拉底式对话的 AI 技能，帮助用户通过温和对话逐步澄清模糊想法，识别真正的需求。

**核心能力：**
- 跨会话记忆：记住你说过的话，识别矛盾与回避
- 结构化澄清：从模糊想法逐步提炼需求框架
- 温和跟随：一次一个问题，反射式倾听，从不评判

---

## 安装方法

### 前提条件

确保你已安装 Hermes Agent。如果没有，访问 https://hermes-agent.nousresearch.com/ 安装。

### 步骤 1：解压技能包

```bash
# 进入你的技能目录
cd ~/.hermes/skills

# 解压
tar -xzvf hum-socratic-v2.tar.gz

# 删除压缩包（可选）
rm hum-socratic-v2.tar.gz
```

### 步骤 2：验证安装

启动 Hermes Agent 后，技能会自动加载。你可以用以下方式验证：

```bash
hermes skills list | grep hum-socratic
```

应该看到 `hum-socratic` 出现在列表中。

### 步骤 3：开始使用

直接对我说以下任一触发词：

- "帮我分析下我到底想要什么"
- "我不知道我到底想做什么"
- "帮我理清楚"
- "用 hum-socratic 跟我聊"

我会自动加载技能开始对话。

## 使用方法

### 对话流程

技能会引导你经历以下阶段：

1. **建立安全感** — 自由表达，不用组织语言
2. **识别表层诉求** — 找出你最在意的那件事
3. **深层追问** — 用"如果实现了会怎样/如果不做会怎样/谁在说话"等策略深挖
4. **结构化澄清** — 逐步提炼六个维度：问题域、用户、功能/范围、非功能、数据/集成、约束
5. **浮现核心** — 压缩成一句话
6. **确认与收尾** — 你带走一个发现

### 跨会话记忆

技能会自动记录每次对话的状态到 `~/.hermes/skills/hum-socratic/state/`：

- `profile.json` — 你的价值观、理想自我、能量来源
- `sessions.json` — 对话记录
- `trajectory.md` — 你的演变叙事

下次对话时，我会读取这些文件，记得你之前说过什么。

## 与 freud-qa 的区别

| | hum-socratic v2 | freud-qa |
|---|---|---|
| **记忆** | 跨会话持久化 | 单会话 |
| **结构化** | 产出六维需求框架 | 自由联想 |
| **矛盾追踪** | 有 | 无 |
| **时间价值** | 有 | 无 |
| **适用场景** | 长期自我探索+需求澄清 | 单次深度挖掘 |

---

## 注意事项

1. **状态目录**：`state/` 目录会在首次对话时自动创建，用于存储你的个人信息。你可以随时删除这个目录重新开始。

2. **隐私**：所有数据存储在本地，不会上传到任何服务器。

3. **语言**：技能会根据你的回答自动切换语言。默认中文，如果你用英文回复，我会切换到英文。

4. **深度**：信任是逐步建立的。第一次对话比较浅，后续对话会深入。不要着急。

## 常见问题

**Q: 如何删除我的数据重新开始？**
A: 删除 `~/.hermes/skills/hum-socratic/state/` 目录即可。

**Q: 我可以导出对话记录吗？**
A: 直接查看或复制 `~/.hermes/skills/hum-socratic/state/sessions.json` 即可。

**Q: 技能会主动发消息提醒我吗？**
A: 不会。hum-socratic 是被动响应的，只有你主动触发才会开始对话。
